# Svelte Component

Reusable Svelte component for loading and displaying images with loading states. Wraps the `ImageFetcher` with a shimmer placeholder.

> For rendering avatars from sprite sheets generated by the CVM, see the `SpriteDisplay` component in [`spa/`](../spa/README.md) or the sprite utilities in [`@spryte/client`](../client/README.md).

## Usage

```svelte
<script>
  import SpryteLoader from "@spryte/svelte/SpryteLoader.svelte";
</script>

<!-- Direct URL -->
<SpryteLoader
  imageUrl="https://example.com/image.png"
  timeout={5000}
  defaultImage="path/to/default.png"
/>

<!-- From key-based mapping -->
<SpryteLoader
  mapping={{ profile1: "https://example.com/profile1.png" }}
  mappingKey="profile1"
  timeout={5000}
  defaultImage="path/to/default.png"
/>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `imageUrl` | `string` | `''` | URL of the image to load |
| `mapping` | `object \| null` | `null` | Object mapping keys to image URLs |
| `mappingKey` | `string \| null` | `null` | Key to look up in the mapping |
| `timeout` | `number` | `5000` | Fetch timeout in milliseconds |
| `defaultImage` | `string` | placeholder URL | Fallback image URL |

## Loading States

- **Loading**: Shimmer animation placeholder
- **Loaded**: Renders the fetched image
- **Error**: Falls back to `defaultImage`
