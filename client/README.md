# Client Library (`@spryte/client`)

Turnkey client library for generating and consuming Spryte sprite sheets. Connects to the Spryte CVM over Nostr, handles payments, and provides utilities for rendering avatars from sprite sheets.

## Install

```bash
npm install @spryte/client
```

## Quick Start

```typescript
import { Spryte } from "@spryte/client";
import { fromApplesauce } from "@spryte/client/signers";
import { ExtensionSigner } from "applesauce-signers";

const spryte = new Spryte({
  signer: fromApplesauce(new ExtensionSigner()),
  serverPubkey: "spryte-cvm-hex-pubkey",
});

await spryte.connect();

// Generate a sprite sheet and load it for rendering
const sheet = await spryte.generate("target-hex-pubkey");

// Render an avatar
const style = spryte.getAvatarStyle(sheet, "some-follower-pubkey", 48);
if (style) {
  element.setAttribute("style", spryte.avatarStyleToString(style));
}

await spryte.disconnect();
```

## Signers

The client accepts any signer implementing the `Signer` interface. Use the `fromApplesauce` adapter for applesauce-signers:

```typescript
import { fromApplesauce } from "@spryte/client/signers";
import { ExtensionSigner, NostrConnectSigner, PrivateKeySigner } from "applesauce-signers";

// NIP-07 browser extension (nos2x, Alby, etc.)
const signer = fromApplesauce(new ExtensionSigner());

// NIP-46 remote signer via bunker URI
const ncs = NostrConnectSigner.fromBunkerURI("bunker://...");
await ncs.connect();
const signer = fromApplesauce(ncs);

// Direct private key (for server-side / scripts)
const signer = fromApplesauce(new PrivateKeySigner(hexSecretKey));
```

Custom signers can implement the `Signer` interface directly:

```typescript
import type { Signer } from "@spryte/client/signers";

const mySigner: Signer = {
  getPublicKey: () => "...",
  signEvent: (template) => { /* sign and return */ },
};
```

## API Layers

### High-level: `Spryte`

All-in-one class — connect, generate, load, render.

```typescript
const spryte = new Spryte(options: SpryteOptions);  // signer + serverPubkey required

await spryte.connect();
await spryte.disconnect();

// Generate via CVM and load the result
const sheet = await spryte.generate(pubkey, cellSize?, uploadServer?);

// Get raw CVM result without loading the sprite
const result = await spryte.generateRaw(pubkey, cellSize?, uploadServer?);

// Load an existing sprite from known URLs (no CVM call)
const sheet = await spryte.load(spriteUrl, mappingUrl);

// Render helpers
const style = spryte.getAvatarStyle(sheet, pubkey, displaySize?);
const css = spryte.avatarStyleToString(style);
```

### Low-level: `SpryteCvmClient`

Type-safe CVM client generated by [`@contextvm/ctxcn`](https://www.npmjs.com/package/@contextvm/ctxcn). Direct MCP tool calls.

```typescript
import { SpryteCvmClient, fromApplesauce } from "@spryte/client";
import { PrivateKeySigner } from "applesauce-signers";

const client = new SpryteCvmClient({
  signer: fromApplesauce(new PrivateKeySigner("hex-secret-key")),
  serverPubkey: "...",
});
await client.connect();

const result = await client.generateSpryte("hex-pubkey", 128);
// { spriteUrl, mappingUrl, pubkeyCount, cellSize }

await client.disconnect();
```

### Utilities: Sprite consumption

Standalone functions for loading and rendering sprites — usable without the CVM.

```typescript
import {
  loadSpriteSheet,
  getAvatarStyle,
  avatarStyleToString,
  fetchMapping,
  getPubkeys,
  hasPubkey,
} from "@spryte/client";

const sheet = await loadSpriteSheet(spriteUrl, mappingUrl);
const pubkeys = getPubkeys(sheet.mapping);
const style = getAvatarStyle(sheet, pubkeys[0], 64);
```

## ctxcn Integration

The CVM client in `src/ctxcn/SpryteCvmClient.ts` matches the output format of [`@contextvm/ctxcn`](https://www.npmjs.com/package/@contextvm/ctxcn). Once the CVM is deployed:

```bash
# Regenerate from the live server
npx ctxcn add <cvm-pubkey>

# Update existing client when tools change
npx ctxcn update
```

Configuration is in `ctxcn.config.json`.

## Types

| Type | Description |
|------|-------------|
| `SpryteOptions` | Constructor options for `Spryte` |
| `Signer` | Interface for Nostr event signing (`getPublicKey`, `signEvent`) |
| `ApplesauceSigner` | Structural type matching applesauce-signers `ISigner` |
| `GenerateSpryteInput` | CVM tool input (`pubkey`, `cellSize?`, `uploadServer?`) |
| `GenerateSpryteOutput` | CVM tool output (`spriteUrl`, `mappingUrl`, `pubkeyCount`, `cellSize`) |
| `SpriteMapping` | Parsed mapping JSON (`cellDimensions`, `mapping`) |
| `SpriteSheet` | Loaded sprite with mapping and image dimensions |
| `SpriteAvatarStyle` | CSS properties for a single avatar |
