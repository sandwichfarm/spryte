# Client Library

`@spryte/client` provides three API layers for working with Spryte: a high-level `Spryte` class, a low-level `SpryteCvmClient`, and standalone utility functions.

## Install

```bash
npm install @spryte/client
```

## High-Level: `Spryte`

The all-in-one class that handles connection, generation, loading, and rendering.

### Constructor

```typescript
import { Spryte } from "@spryte/client";

const spryte = new Spryte(options: SpryteOptions);
```

#### `SpryteOptions`

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `privateKey` | `string` | Yes | Hex Nostr private key for client identity |
| `serverPubkey` | `string` | Yes | CVM server pubkey |
| `relays` | `string[]` | No | Nostr relay URLs (default: `["wss://relay.damus.io"]`) |
| `nwcConnectionString` | `string` | No | NWC connection string for automatic Lightning payments |
| `transportOptions` | `Partial<NostrTransportOptions>` | No | Additional transport configuration |

### Methods

#### `connect()` / `disconnect()`

```typescript
await spryte.connect();
// ... use the client ...
await spryte.disconnect();
```

#### `generate(pubkey, cellSize?, uploadServer?)`

Generate a sprite sheet and load it for immediate rendering. This is the primary method — it calls the CVM, then fetches and parses both the sprite image and mapping JSON.

```typescript
const sheet: SpriteSheet = await spryte.generate("hex-pubkey");

// With options
const sheet = await spryte.generate("hex-pubkey", 256, "https://blossom.example");
```

#### `generateRaw(pubkey, cellSize?, uploadServer?)`

Get the raw CVM result without loading the sprite. Use this when you only need the URLs.

```typescript
const result: GenerateSpryteOutput = await spryte.generateRaw("hex-pubkey");
// { spriteUrl, mappingUrl, pubkeyCount, cellSize }
```

#### `load(spriteUrl, mappingUrl)`

Load an existing sprite from known URLs without making a CVM call.

```typescript
const sheet: SpriteSheet = await spryte.load(spriteUrl, mappingUrl);
```

#### `getAvatarStyle(sheet, pubkey, displaySize?)`

Get CSS properties for rendering a single avatar. Returns `null` if the pubkey isn't in the mapping.

```typescript
const style: SpriteAvatarStyle | null = spryte.getAvatarStyle(sheet, pubkey, 48);
```

#### `avatarStyleToString(style)`

Convert a `SpriteAvatarStyle` to a CSS string for use in `style` attributes.

```typescript
const css: string = spryte.avatarStyleToString(style);
element.setAttribute("style", css);
```

## Low-Level: `SpryteCvmClient`

Type-safe CVM client generated by [`@contextvm/ctxcn`](https://www.npmjs.com/package/@contextvm/ctxcn). Use this when you need direct control over the MCP connection.

```typescript
import { SpryteCvmClient } from "@spryte/client";

const client = new SpryteCvmClient({
  privateKey: "your-hex-key",
  serverPubkey: "cvm-pubkey",
  relays: ["wss://relay.damus.io"],
});

await client.connect();
const result = await client.generateSpryte("hex-pubkey", 128);
// { spriteUrl, mappingUrl, pubkeyCount, cellSize }
await client.disconnect();
```

## Utility Functions

Standalone functions for loading and rendering sprites. These work without the CVM — you only need sprite URLs.

```typescript
import {
  loadSpriteSheet,
  fetchMapping,
  getAvatarStyle,
  avatarStyleToString,
  getPubkeys,
  hasPubkey,
} from "@spryte/client";
```

### `loadSpriteSheet(spriteUrl, mappingUrl)`

Fetch the mapping JSON and probe the sprite image dimensions. Returns a `SpriteSheet`.

```typescript
const sheet = await loadSpriteSheet(spriteUrl, mappingUrl);
```

### `fetchMapping(mappingUrl)`

Fetch and parse only the mapping JSON.

```typescript
const mapping: SpriteMapping = await fetchMapping(mappingUrl);
```

### `getAvatarStyle(sheet, pubkey, displaySize?)`

Compute CSS properties for a single avatar from a loaded sprite sheet.

```typescript
const style = getAvatarStyle(sheet, "some-pubkey", 64);
// { backgroundImage, backgroundPosition, backgroundSize, backgroundRepeat, width, height }
```

### `avatarStyleToString(style)`

Convert a `SpriteAvatarStyle` to a CSS string.

### `getPubkeys(mapping)`

Get all pubkeys present in a sprite mapping.

```typescript
const pubkeys: string[] = getPubkeys(sheet.mapping);
```

### `hasPubkey(mapping, pubkey)`

Check if a pubkey exists in a sprite mapping.

```typescript
if (hasPubkey(sheet.mapping, "some-pubkey")) { ... }
```

## Types

### `SpriteMapping`

```typescript
interface SpriteMapping {
  cellDimensions: { width: number; height: number };
  mapping: Record<string, { x: number; y: number; source: string }>;
}
```

### `SpriteSheet`

```typescript
interface SpriteSheet {
  spriteUrl: string;
  mapping: SpriteMapping;
  imageWidth: number;
  imageHeight: number;
}
```

### `SpriteAvatarStyle`

```typescript
interface SpriteAvatarStyle {
  backgroundImage: string;
  backgroundPosition: string;
  backgroundSize: string;
  backgroundRepeat: string;
  width: string;
  height: string;
}
```

### `GenerateSpryteInput`

```typescript
type GenerateSpryteInput = {
  pubkey: string;
  cellSize?: number;
  uploadServer?: string;
};
```

### `GenerateSpryteOutput`

```typescript
type GenerateSpryteOutput = {
  spriteUrl: string;
  mappingUrl: string;
  pubkeyCount: number;
  cellSize: number;
};
```
